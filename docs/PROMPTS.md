## 2026-11-17 — 파일 분리

### P-01 프로젝트 이어서 진행 + 순수 웹 리소스로 분리
> 첨부한 컨텍스트 참고해서 이어서 진행해보자
> 읽어보고 첨부한 html파일을 순수 웹리소스로 파일들만 구분해서 만들어줘
> html,css,js 동작이나 디자인등 동일하게
> 코드만 분리시켜줘 유지보수 쉽게 주석꼭 달아주고 컴포넌트 정리도 필요하면 해줘 vs코드에 바로 붙여넣을거야

- **의도**: 동작·디자인은 그대로, 파일만 분리 + 유지보수성 향상
- **결과**: `index.html` + `css/style.css` + `js/*.js` 14개. `build()`를 8단계로 분리
- **배운 점**: "동일하게"를 지키려면 구조 정리(컴포넌트화)는 **동작이 바뀌지 않는 범위**로 제한해야 한다. `file://` 실행을 위해 ES 모듈 대신 일반 스크립트 선택.

## 프롬프트 작성 팁 (이 프로젝트에서 효과적이었던 방식)

1. **동작은 동일하게**처럼 *바꾸지 말아야 할 것*을 명시한다.
2. **제약**(주석, 보안, 접근성, 모바일 확인)을 처음에 한 번 정해 두고 계속 재사용한다.
3. **구현 안 된 것을 완성처럼 표시하지 않는다** 같은 정직성 규칙을 명시한다.
4. 직접 실행 확인이 어려운 경우, **검증 방법(문법 검사 등)과 한계**를 함께 요청/기록한다.
