# 🚂 느린 기차 (Slow Train)

> 옛 **무궁화호** 감성의 힐링형 **3D 미니어처 기차 웹게임**
> 설치 없이 브라우저에서, 천천히 달리는 객차에 올라 창밖 풍경을 바라보세요.

**상태**: 싱글플레이 베타 · **플랫폼**: 웹(PC/모바일) · **언어**: 한국어

---

## ✨ 프로젝트 소개

경쟁 없이 **그냥 쉬어 가는 게임**을 목표로 만든 개인 프로젝트입니다.
플레이어는 객차를 걸어 다니고, 자리에 앉아 창밖 풍경을 보고, 승객과 말풍선으로 인사하고, 간식 판매원에게 간식을 삽니다.
승무원의 **표 검사**가 있어 무임승차를 하면 퇴장당할 수 있고, 의자 틈에 **숨을 수도** 있어요.

> 실제 접속자는 아직 없습니다. "베타 승객" NPC가 대신 탑승하며, 이름표에 **"베타"**가 붙어 구분됩니다.
> 승차권·간식 구매는 **가상**이며 실제 결제는 없습니다.

## 🎮 주요 기능

- **3D 객차** — 컷어웨이 시점, 창문 16개, 햇살 그림자, 32석 (2인석 24 + 4인석 테이블 8)
- **반응형 시점** — 드래그 회전, 휠/핀치 확대·축소, 가로(PC)/세로(모바일) 자동 시점
- **흐르는 창밖 풍경** — 산·언덕·논밭·나무·집이 시차를 두고 반복 스크롤
- **자유로운 이동** — WASD/방향키, 바닥 터치 이동, 좌석 클릭 착석
- **베타 승객 NPC 5명** — 앉기/걷기/말풍선, 겹침·중복 착석 방지
- **간식 판매원** — 정차·말걸기·메뉴 5종(가상 구매)·손에 들기
- **승무원 검표** — 표 보여주기 / 표 없음 → 5초 카운트다운 → 강제 퇴장
- **숨는 곳** — 의자 등받이 사이 틈에서 웅크려 숨기
- **기차 소리** — 코드로 만든 합성음, 음소거/볼륨 설정 유지
- **자동 저장** — 닉네임·좌석·위치 복원

## 🛠 기술 스택

| 영역 | 사용 기술 |
| --- | --- |
| 언어 | HTML5, CSS3, JavaScript (ES2020, 빌드 도구 없음) |
| 3D | [Three.js](https://threejs.org/) r128, OrbitControls (CDN) |
| 사운드 | Web Audio API (합성음) |
| 저장 | localStorage (어댑터 패턴 → Supabase로 교체 예정) |
| 에셋 | 없음 — 모든 3D 모델을 코드로 생성 |

## 🚀 실행 방법

```bash
# 방법 1) index.html을 브라우저로 더블클릭
# 방법 2) VS Code Live Server 확장으로 index.html 열기
# 방법 3) 간단한 정적 서버
npx serve .
```

- 인터넷 연결 필요 (Three.js CDN)
- 일반 `<script>`만 사용하므로 `file://`로 열어도 동작합니다.

## 🎛 조작법

| 입력 | 동작 |
| --- | --- |
| `WASD` / 방향키 | 이동 (카메라 기준) |
| 바닥 클릭·터치 | 그 위치로 이동 |
| 좌석 클릭·터치 | 착석 / **일어나기** 버튼 |
| 드래그 / 휠 / 핀치 | 시점 회전 / 확대·축소 |
| 판매원 근처 → **말걸기** | 간식 메뉴 |
| **말풍선** 버튼 | 문구 선택 |
| 의자 틈 클릭 | 들어가기 / **나가기** |

## 🧠 설계 포인트

- **Actor 공통 구조** — 플레이어·NPC·판매원·승무원이 같은 상태 구조(`idle | sit | hide`, 경로, 좌석 예약)를 쓰고, 행동 로직(`brain`)만 분리해 **실제 접속자로 교체하기 쉽게** 설계했습니다.
- **좌석 점유 관리** — 고유 좌석 ID와 `occ[seatId]`로 예약/점유를 관리해 중복 착석을 막습니다.
- **저장소 어댑터** — 게임 코드는 `Repo`만 알고 저장 방식은 모릅니다. `LocalRepo` → `SupabaseRepo` 교체가 한 줄로 가능합니다.
- **리소스 정리** — 말풍선/이름표 텍스처는 사용 후 `dispose`해 메모리 누적을 막습니다.
- **접근성 기본기** — 키보드 조작, `:focus-visible` 표시, 다크모드, 안전 영역(`env(safe-area-inset-*)`) 대응.
- **유지보수** — 모든 함수/블록에 한글 주석, 기능별 파일 분리.

## 🧩 문제 해결 사례

| 문제 | 해결 |
| --- | --- |
| 같은 좌석에 여러 명이 앉음 | 좌석 예약/점유 표(`occ`)로 거부 처리 |
| 통로에서 인물끼리 겹침 | `separate()`로 서로 밀어내기 |
| 브라우저가 소리 재생을 막음 | 입장 버튼 클릭 직후 오디오 시작, 중단 시 다음 터치에서 재개 |
| 숨을 때 이름표가 찌그러짐 | 몸 스케일의 역수로 이름표 보정 |
| `file://`에서 파일 분리가 막힘 | ES 모듈 대신 일반 스크립트 + 고정 로딩 순서 |
